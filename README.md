# Mochila Once

Proyecto de pruebas y prototipo para una mochila inteligente. Incluye pruebas de sensores y modulos (BLE, WiFi, RFID, ultrasonido, vibracion, buzzer, VL53L0X) y el sketch principal.

## Estructura

- archivo/: notas y resumen del proyecto
- src/: sketches de Arduino

## Uso

- Abre el sketch que quieras en el IDE de Arduino.
- Ajusta pines y parametros segun tu hardware.
- Sube al microcontrolador correspondiente.
